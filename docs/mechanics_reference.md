# Биомеханика симулятора: параметры в σ-единицах

## Что такое сигма (σ)

Все концентрации в симуляторе — пища, энергия, токсины, клеточные продукты — выражены в **σ-единицах** (стандартных отклонениях). Шкала симметрична относительно нуля:

| Значение | Смысл |
|----------|-------|
| −3 σ | Критически низкий / полное отсутствие |
| 0 σ | Среднее, базовый уровень |
| +3 σ | Очень высокий / критически много |

Верхняя и нижняя границы ±3 σ — жёсткие пределы для большинства переменных среды. Внутри клетки энергия может выйти за −3 σ (что ведёт к гибели).

---

## 1. Пища (Food)

### Как устроена пища в среде

Пища в среде хранится в σ-единицах и каждый такт **регенерирует на +1 σ** — это базовый приток питательных веществ. Значение зажато в диапазоне [−3, +3] σ.

Начальный уровень пищи задаётся в настройках среды (по умолчанию −3 σ — почти пусто).

### Как гены извлекают энергию из пищи

Гены с функцией `energy` (например, HARVEST, FEED, SAFEED) перерабатывают пищу в клеточную энергию.

**Формула за один такт:**

```
available = food − (−3.0)              # сколько пищи доступно выше нижней границы
used      = min(available, eff_prot × coeff)  # сколько ген способен переработать
energy   += used × efficiency          # зачисляется на баланс клетки
food     −= used × support_ratio       # пища вычитается из общей среды
```

**Коэффициент эффективности** зависит от начального уровня пищи в среде (`init_food` — значение в начале тика, до регенерации):

| Уровень пищи (init_food) | Эффективность переработки |
|--------------------------|--------------------------|
| −3 σ (голодно) | 0.5 (50 %) |
| −2 σ | 0.67 (67 %) |
| −1 σ | 0.83 (83 %) |
| 0 σ | 1.0 (100 %) |
| +1 σ | 1.33 (133 %) |
| +2 σ | 1.67 (167 %) |
| +3 σ (изобилие) | 2.0 (200 %) |

Точная формула:
- Если `init_food ≤ 0`: `eff = 0.5 + (init_food + 3) × (0.5 / 3)`
- Если `init_food > 0`: `eff = 1.0 + init_food × (1.0 / 3)`

**Что это значит на практике:** при почти пустой среде (−3 σ) клетка получает вдвое меньше энергии из той же массы переработанной пищи. При изобилии (+3 σ) — вдвое больше, чем при «нормальных» условиях.

**support_ratio** — доля ёмкости среды, занятая популяцией:

```
support_ratio = суммарное количество клеток / ёмкость среды (support_cell_num)
```

Это означает, что при большой популяции пища из общего бассейна убывает быстрее — конкуренция.

## 2. Клеточная энергия (Energy)

Энергия — внутренний баланс клетки, выраженный в σ. В отличие от пищи, энергия **не зажата** сверху и снизу: она может уйти глубоко в отрицательную зону, что ведёт к гибели.

### Приход энергии
- Переработка пищи генами `energy` (см. раздел 1)
- Переработка белков генами `process` (аутофагия)
- Переработка мРНК генами `RNAdigest`

### Расход энергии
- **Поддержание экспрессии:** каждый такт вычитается `sum(new_expr) × energy_cost`
  - `energy_cost = 1 / (число_генов × 16)` — масштабируется с размером генома
- **Деление:** вычитается `division_cost` (задаётся функцией `div`)
- **Токсины:** прямые штрафы к энергии (см. раздел 3)
- **Секреция:** гены `secret` вычитают `delta × energy_cost_per_unit`

### Гибель клеток (Cell death)

Вероятность гибели одной клетки за такт — **логистическая функция** от абсолютного значения энергии:

```
death_prob = 1 / (1 + exp(−3 × (|energy| − 3.5)))
```

| Энергия | Вероятность гибели за такт |
|---------|---------------------------|
| 0 σ | ≈ 0.02 % (практически нулевая) |
| ±1 σ | ≈ 0.06 % |
| ±2 σ | ≈ 0.4 % |
| ±3 σ | ≈ 7 % |
| ±4 σ | ≈ 62 % |
| ±5 σ | ≈ 95 % |

**Важно:** функция симметрична — клетки гибнут как от истощения (energy → −∞), так и теоретически от «перекорма» (energy → +∞). На практике второе крайне редко.

При численности популяции ≤ 100 гибель стохастична (каждая клетка «бросает кубик»). При > 100 клетках применяется детерминированное округление: `survived = int(N × (1 − death_prob))`.

## 3. Токсины

### Концентрация токсина в σ-единицах

Начальный уровень каждого токсина задаётся при создании среды. Например, −2 σ означает что токсин присутствует, но на пониженном фоновом уровне; +1 σ — заметная концентрация.

Уровень токсина меняется:
- Растёт от клеточных продуктов (Wastetoxin, CytokineX и т.д.)
- Снижается генами `detox`

### Как токсин наносит урон: функция `toxin_effect`

```
effect = base_effect × exp(sigma)
```

Экспонента создаёт **логарифмическое восприятие концентрации**: при возрастании sigma на 1 эффект увеличивается в `e ≈ 2.718` раза.

| sigma токсина | Эффект (при base_effect = 0.2) |
|---------------|-------------------------------|
| −3 σ | 0.2 × e⁻³ ≈ 0.010 |
| −2 σ | 0.2 × e⁻² ≈ 0.027 |
| −1 σ | 0.2 × e⁻¹ ≈ 0.074 |
|  0 σ | 0.2 × e⁰  = 0.200 |
| +1 σ | 0.2 × e¹  ≈ 0.544 |
| +2 σ | 0.2 × e²  ≈ 1.478 |
| +3 σ | 0.2 × e³  ≈ 4.018 (жёсткий предел) |

Значение sigma зажато в [−8, +3] при расчёте эффекта.

### Параметр `param` токсина: на что действует

| param | Что снижается |
|-------|--------------|
| `energy` | Прямой вычет из энергии клетки: `energy −= effect` |
| `TPM` | Штраф к росту экспрессии: `new_expr ×= (1 − min(effect, 1))` |
| `common` | Одновременно energy И TPM |

### Детоксикация: ген `detox`

Ген `detox` снижает sigma **всех** токсинов в общей среде:

```
detox_power = eff_prot × cell_count × coeff × support_ratio
sigma_new   = max(−3.0, sigma − detox_power)
```

Важно: детокс действует на **общую среду** — все геномы выигрывают от чужой детоксикации.

### Резистентность: ген `toxresist`

В отличие от `detox`, ген `toxresist` **не очищает среду**. Он снижает `local_penalties` только для данного генома:

```
reduction      = prev_prot × coeff
local_penalty  = max(0, tox_penalty − reduction)
```

Sigma токсина в среде остаётся прежней — другие геномы не получают выгоды.

### Детекция токсинов: ген `toxsens`

Детекция — вероятностный процесс. Ген вычисляет «сигнал» по формуле:

```
score = (expr × exp(total_toxins)) / (64 × detect_coeff)
```

Если `score > 1` — токсин считается обнаруженным (`Toxin_detected = True`), и условие `Toxin_detected == True` становится доступно другим генам. При низкой концентрации токсина или слабой экспрессии гена сенсор может «промолчать».

## 4. Клеточные продукты

Продукты накапливаются в среде начиная с −3 σ. Каждый такт к уровню продукта добавляется:

```
total_delta = delta_per_cell × support_ratio
env_product += total_delta
```

### Режимы секреции

| Источник (`mode`) | Формула `delta_per_cell` |
|-------------------|--------------------------|
| `energy` | `coeff × energy_spent_this_tick` |
| `TPMsum` | `coeff × sum(всех TPM клетки)` |
| `secret:<ген>` | `coeff × protein_level[ген]` |

**support_ratio** учитывает, что в большой популяции продукта выделяется больше.

### Wastetoxin (неотключаемый)

Wastetoxin всегда секретируется пропорционально потраченной энергии (mode = `energy`, coeff = 0.005). Он неизбежен — метаболические отходы производятся при любой активности. Если Wastetoxin зарегистрирован как токсин в среде, его накопление отравляет среду при высоком population density.

### CytokineX (опциональный)

CytokineX секретируется пропорционально суммарной транскрипционной активности (mode = `TPMsum`, coeff = 0.0001). Высокая суммарная экспрессия всех генов = высокая секреция CytokineX.

### Секреция через белок (`secret`)

Если ген имеет функцию `secret`, его белок напрямую секретирует продукт в среду. Уровень секреции пропорционален **количеству белка** (а не mRNA), поэтому:
- Эффект появляется с задержкой 1–3 такта после активации гена (время синтеза белка)
- После деактивации гена секреция продолжается пока белок не деградирует

## 5. Экспрессия генов (TPM)

### Что такое TPM в данном контексте

TPM (Transcripts Per Million — адаптированно) — количественная мера транскрипционной активности гена. Минимальное значение = 1 (ген «молчит», но не мёртв). Максимум ограничен энхансером.

### Рост экспрессии

Каждый такт, пока ген активен:

```
new_expr = min(prev_expr × promoter, enhancer)
```

- **Промотор** (числовой множитель): типичные значения 1.25 / 2.0 / 4.0. При промоторе 2.0 экспрессия удваивается каждый такт.
- **Энхансер** (числовой потолок): типичные значения 4 / 16 / 64. Задаёт максимальный уровень экспрессии.

Пример: ген с промотором 2.0 и энхансером 16 достигает максимума за 4 такта (1 → 2 → 4 → 8 → 16).

Токсины типа `TPM` снижают новую экспрессию: `new_expr ×= (1 − tpm_penalty)`.

### Активация гена

Ген переходит в статус `active` когда:
1. Все условия ON выполнены
2. Ни одно условие OFF не выполнено
3. `new_expr ≥ threshold` (TPM достиг порога)

**Гистерезис:** если условие OFF выполнилось, ген деактивируется со сдвигом на один такт — это предотвращает мгновенные переключения.

### Белок

Белок синтезируется из мРНК предыдущего такта и деградирует:

```
protein = prev_protein × stability × size_modifier(kDa) + max(0, prev_expr − 1)
```

- `stability` задаётся глобально (0 – 1)
- `size_modifier`: белки ≤ 10 kDa деградируют медленнее (множитель 1.0), белки ≥ 150 kDa — в 4 раза быстрее (множитель 0.25)

Функция гена (energy, detox, div и т.д.) выполняется только если `protein ≥ threshold`.
